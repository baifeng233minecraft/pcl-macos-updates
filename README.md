# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.1.1 更新介绍

这一版重点升级实验室汉化：现在可以调用百度翻译或多种大模型翻译，并导出能直接放进实例 `mods` 文件夹的汉化 Mod `.jar`。

### 实验室汉化

- 汉化引擎新增百度翻译。
- 新增 OpenAI、DeepSeek、通义千问、智谱 AI、Kimi / Moonshot、豆包、Gemini 等大模型选项。
- 大模型翻译支持填写 API Key、模型名和接口地址，可接入兼容 OpenAI 格式的服务。
- 新增“复制 AI 接管提示词”，可把扫描结果复制给外部 AI 继续翻译。
- 自动翻译时显示实时进度条和百分比。
- 英文会尽量完整扫描，包括语言资源和疑似写在代码常量里的英文。

### 汉化 Mod 导出

- 导出结果从普通覆盖包改为 `.jar`。
- 默认文件名改为 `原文件名-BCL汉化.jar`。
- 生成的 `.jar` 可以直接放进实例 `mods` 文件夹。
- 汉化 `.jar` 会包含 `assets/.../lang/zh_cn.json` 或 `zh_cn.lang`。
- 自动附带 `fabric.mod.json`、`META-INF/mods.toml` 和 `META-INF/neoforge.mods.toml`，便于 Fabric、Forge、NeoForge 识别。
- 代码内英文仍会写入审查报告，不直接修改原 Mod 的 `.class` 文件，避免破坏模组。

### 继承 v1.1.0 内容

- 修复红石联机官网文件不存在时，启动器仍把错误页面当成内核下载的问题。
- 红石联机失败界面新增“导入内核”。
- 修复本机没有联机软件时直接报错的问题。
- 新增访客模式与信任模式账号保存方式。
- 默认使用访客模式，将正版和第三方登录令牌保存到 macOS 钥匙串。
- 信任模式保存到本机加密文件。
- 删除登录页左侧的大段提示字幕。

# pcl-macos-updates
PCL macOS 独立移植版的公开更新源与安装包

## v1.0.0 更新介绍

从这一版开始，PCL macOS 独立移植版使用自己的语义版本号 `v1.0.0`，不再沿用原版 PCL 的版本号。旧版内部更新码会继续兼容，因此 `v24` 及更早版本仍能正常检测本次更新。

### 一次授权更新

- “设置 → 软件更新”新增“一次授权”。
- 启用后启动器会安装到当前用户的 `~/Applications` 并重新打开。
- 后续更新直接替换用户拥有的副本，不索要管理员密码，也不保存系统密码。
- 即使没有提前设置，自动更新也会回退到用户应用程序目录。
- 更新包继续验证文件大小、SHA-256 和应用标识，替换失败时恢复旧版本。

### 更新与主页设置

- 软件更新可选择启动时发现新版本后立即安装、是否显示更新提示，并可随时手动检查。
- 主页快捷游戏可以单独关闭，也可以选择显示最近实例、最近服务器与最大条目数。
- 快捷游戏设置与自定义主页并存，不会覆盖已有主页内容。

### 实例文件夹与动画性能

- 实例选择支持创建新的 Minecraft 文件夹，用户可设置位置和名称，并一次创建多个文件夹。
- 多个文件夹中的实例会统一显示，同时保留各自独立的游戏文件。
- 移除容易造成卡顿的根视图隐式动画、列表入场风暴和持续时间轴刷新。
- “设置 → 个性化 → 更多动画”可以控制丰富动画，关闭后保留必要的状态反馈。

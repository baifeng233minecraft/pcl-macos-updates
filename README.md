# pcl-macos-updates
PCL macOS 独立移植版的公开更新源与安装包

## v1.0.1 更新介绍

这一版继续优化启动器的操作手感，为左侧列表加入连贯的选中项移动动画。

### 列表移动动画

- 点击侧栏分类时，选中背景会自然滑动到新条目，不再直接跳变。
- 左侧红色指示条与选中背景同步移动，避免两个状态元素脱节。
- 动画已覆盖设置、下载和实例设置等共用侧栏。
- 使用短时弹性过渡，在保持灵动感的同时避免增加点击等待。

### 动画与可访问性

- 动画继续受“设置 → 个性化 → 更多动画”控制。
- 开启 macOS“减少动态效果”时，列表会立即切换，不强制播放位移动画。
- 不加入持续刷新或无意义的循环动画，减少对滚动与点击流畅度的影响。

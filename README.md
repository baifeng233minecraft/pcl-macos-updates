# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.1.2 更新介绍

这一版新增完整的动画细分控制，并让实验室汉化正式支持光影包；同时加入 BCL 模组实验室。

### 动画个性化

- 动画速度可在 `0.5×` 到 `2.0×` 之间调节，并实时生效。
- 按钮反馈、页面切换、列表移动、选中放大和卡片进入动画可以分别开启或关闭。
- 关闭动画只会取消视觉效果，不会影响按钮、列表和页面功能。

### 光影包汉化

- 内容汉化工坊现在会识别光影包中的 `shaders/lang` 英文语言文件。
- 光影语言文件会按原目录生成对应的 `zh_cn.lang` 或 `zh_cn.properties`。
- 汉化光影包导出为 `.zip`，可直接放进实例的 `shaderpacks` 文件夹。
- Mod 与资源包仍按原方式生成可放入 `mods` 文件夹的汉化 `.jar`。

### BCL 模组实验室

- 为当前实例安装或更新 BCL 配套模组。
- 检测到配套模组后，可快速打开当前实例的 Mod、配置和存档文件夹。
- 配置文件与存档会在实验室中集中显示，方便直接管理。

### 版本与更新检测

- 同步应用版本为 `v1.1.2`。
- 内部更新码为 `37`。
- 更新包继续只使用 SHA-256 校验。

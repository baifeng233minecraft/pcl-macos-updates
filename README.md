# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.1.0 更新介绍

这一版修复了红石联机下载源异常时的处理方式，同时调整账号令牌保存方式，并清理登录页左侧过长的提示字幕。

### 红石联机与权限

- 修复红石联机官网文件不存在时，启动器仍把错误页面当成内核下载的问题。
- 红石联机内核下载完成后会校验 HTTP 状态、文件大小与错误页面特征，避免保存坏文件。
- 红石联机下载源不可用时，提示改为清楚说明“官网文件不存在或暂时不可下载”。
- 红石联机失败界面新增“导入内核”，可手动选择已下载的 macOS 红石联机内核。
- 修复本机没有联机软件时直接报错的问题，现在会先尝试自动下载，失败后给出可操作提示。
- 改进更新安装前的钥匙串权限交接，旧版会尝试把正版/第三方登录访问权交给新版。

### 账号保存方式

- 新增“访客模式 / 信任模式”账号保存方式。
- 默认使用“访客模式”，正版和第三方登录令牌会保存到 macOS 钥匙串。
- 用户手动切换到“信任模式”后，登录令牌会保存到当前 Mac 的本机加密文件。
- 切换账号保存方式后会立刻刷新当前账号读取状态。

### 登录页界面

- 删除登录页左侧大段账号保存说明字幕。
- 登录页只保留“账号保存方式”选择框，让界面更清爽。
- 同步帮助、导入设置和关于页中的账号令牌保存说明，避免继续显示旧描述。

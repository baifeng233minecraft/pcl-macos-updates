# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.1.0 更新介绍

这一版调整了账号令牌保存方式，并清理登录页左侧过长的提示字幕。

### 账号保存方式

- 新增“访客模式 / 信任模式”账号保存方式。
- 默认使用“访客模式”，正版和第三方登录令牌会保存到 macOS 钥匙串。
- 用户手动切换到“信任模式”后，登录令牌会保存到当前 Mac 的本机加密文件。
- 切换账号保存方式后会立刻刷新当前账号读取状态。

### 登录页界面

- 删除登录页左侧大段账号保存说明字幕。
- 登录页只保留“账号保存方式”选择框，让界面更清爽。
- 同步帮助、导入设置和关于页中的账号令牌保存说明，避免继续显示旧描述。

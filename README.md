# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.0.7 更新介绍

这一版修复汉化任务退出和联机公共节点失效两个会直接阻断使用的问题。

### 汉化任务安全退出

- 离开汉化工坊或切换页面时，正在进行的扫描和导出会安全取消。
- 解压、扫描与打包子进程会随任务一起回收，不会留到关闭启动器时被系统强制终止。
- 取消导出会清理未完成的目标文件，避免留下损坏的汉化包。
- 使用独立操作标识隔离连续任务，旧任务结束时不会覆盖新任务的界面状态。

### 联机节点自动回退

- 移除已经停止解析的 EasyTier 原官方节点。
- 同时连接三个当前可用的社区公共节点，任意一个共同节点可达即可发现房间。
- 创建房间以本地 EasyTier 核心和 RPC 就绪为准，不再因某个远程节点不可达而卡在创建中。
- 加入房间仍会确认实际发现房主后再显示成功，避免假连接。
- 玩家人数只统计房主和加入者，不再把公共中继节点算作玩家；延迟也只显示房间成员链路。

### 验证

- 汉化扫描、已有中文复用、代码文本审计与覆盖包导出集成测试通过。
- 长时间子进程取消测试通过，取消后可在 2 秒内完成回收。
- 两个独立 EasyTier 实例通过公共节点互相发现并进入同一房间的实操测试通过。
- Apple Silicon 应用严格签名校验与两个 ZIP 完整性测试通过。

# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.0.4 更新介绍

这一版集中优化启动器的动画、列表交互、游戏下载贴图和窗口外观，让页面切换更灵动，同时修复 macOS 原生窗口按钮偶发重新出现的问题。

### 动画与交互

- 页面打开与切换改为带轻微缩放和位移的弹簧动画，响应更自然。
- 下载版本和社区资源列表新增分批出现动画，长列表不再同时生硬弹出。
- 详情展开增加平滑高度过渡和箭头旋转动画。
- 刷新游戏版本时新增旋转反馈，快照筛选和结果更新拥有连续过渡。
- 动画继续遵循“更多动画”与 macOS“减少动态效果”设置。

### 列表与页面外观

- 左侧列表的选中、悬停和可点击区域统一为连续圆角轮廓。
- 浅色与深色模式使用各自的悬停亮度，避免列表内容被压暗。
- 取消列表选中时突兀的放大效果，保留清晰但更稳定的选中反馈。
- 启动器标题栏、侧栏、内容区和覆盖层统一裁剪为同一个外轮廓。

### 游戏下载贴图

- 正式版改用草方块贴图。
- 快照版改用命令方块贴图。
- 旧测试版和旧经典版使用对应的金块、圆石贴图。
- 下载列表和版本详情页使用相同的版本类型贴图，不再显示混凝土占位图。

### macOS 窗口修复

- 修复切换应用、最小化恢复、全屏切换或屏幕变化后，macOS 原生红黄绿按钮偶发出现的问题。
- 启动器激活和窗口状态变化时会重新应用自定义标题栏设置。
- 原生关闭、最小化、缩放、工具栏和文档图标按钮均保持隐藏。

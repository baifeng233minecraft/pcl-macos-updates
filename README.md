# pcl-macos-updates
PCL macOS 独立移植版的公开更新源与安装包

## macOS v23 更新介绍

这一版修复深色模式显示问题，让设置导入与导出真正可用，并重新整理“关于与鸣谢”页面。

### 深色模式

- 修复“跟随系统”未及时响应 macOS 外观变化的问题。
- 主题、卡片、Mod 列表、输入框、边框按钮和危险操作按钮会完整适配深色模式。
- 提升深色背景上的层次与文字可读性，避免白色卡片和浅色文字叠在一起。

### 设置导入与导出

- “导出设置”和“导入设置”按钮现在具备实际功能，使用可读的 JSON 配置文件。
- 导入后主题、主页、音乐、启动参数、实例路径等设置立即生效。
- Microsoft 和第三方登录令牌、账号标识不会写入导出文件，导入时也不会覆盖当前钥匙串账号。
- 自动检查无效 Minecraft 文件夹、Java 路径、主题编号和数值范围，并保留当前可用设置。
- 支持读取旧版直接导出的启动器设置文件。

### 关于与鸣谢

- 重写“关于与鸣谢”页面，明确区分 PCL 原作与 macOS 独立移植版。
- 更新实际使用的 Modrinth、EasyTier、LittleSkin、MC 百科等技术与社区鸣谢。
- 所有赞助入口统一指向白枫的爱发电主页：<https://ifdian.net/a/baifeng233>。
- PCL 使用指南与第三方声明随应用打包，可从关于页面直接打开。
- 系统菜单中的关于窗口会显示当前 macOS 版本号与移植版署名。

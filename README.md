# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.0.2 更新介绍

这一版完善了隐藏主题的实际获取流程，同时收录了近期完成的外观、版本维护、崩溃报告与字体管理更新。

> 兼容修复：更新源已将 v1.0.2 标记为必须显示，确保关闭过“发现更新时显示提示”的旧版本也能看到这次更新。v1.0.2 自身不会重复提示。

### 隐藏主题

- 玄素黑、滑稽彩、铁杆粉、神秘紫、欧皇彩、跳票红、极客蓝和自定义主题均有实际可触发的获取逻辑。
- 滑稽彩现在必须在 4 月 1 日点击“启动”后解锁，不会再因日期到来而自动解锁。
- 铁杆粉按启动器累计打开 99 次解锁，跳票红在 Microsoft 正版登录成功后解锁。
- 解锁任意五个隐藏主题后，自定义主题会自动开放。
- 隐藏主题卡片已移除获取方法提示，仅显示名称和解锁状态。
- 按要求不为秋仪金、活跃橙新增独立获取方式；保留现有 `awa` 全部解锁口令。

### 外观与交互

- 修复深色、浅色与跟随系统外观切换后，页面和列表没有立即同步的问题。
- 启动器会监听 macOS 系统外观变化，跟随系统模式无需重启。
- 调整深色与浅色模式的列表悬停色，减少悬停时过暗、文字对比度不足的情况。
- 保留侧栏选中移动动画，并遵循“更多动画”与 macOS“减少动态效果”设置。

### 版本维护、崩溃报告与字体

- “删除版本”现在会安全移到废纸篓，并阻止误删当前 Minecraft 文件夹之外的目录。
- “补全文件”会校验并下载缺失的版本依赖、父版本配置及客户端文件。
- Minecraft 异常退出后可生成本地错误报告，汇总线索、日志和建议，同时隐藏常见敏感字段。
- 支持识别这台 Mac 已安装字体，并可在启动器内搜索、下载和切换在线字体。

# pcl-macos-updates
PCL macOS 独立移植版的公开更新源与安装包

## macOS v22 更新介绍

这一版集中补齐了整合包、正版账号与主页快捷启动体验，并继续保持与 PCL 使用习惯一致。

### 整合包

- 可直接把整合包文件拖入启动器，自动安装到当前实例。
- 支持从“下载”页面选择并安装已有整合包。
- 自动识别 Modrinth、CurseForge、HMCL/MCBBS、MultiMC/Prism 及普通实例压缩包。
- 导入时检查压缩包路径安全性，显示真实进度、安装数量和错误原因。

### 正版账号与头像

- 检测 Modrinth、HMCL 和 Minecraft 官方启动器中已有的正版账号。
- 有效 Minecraft 会话可导入本启动器的 macOS 钥匙串并直接用于正版启动，不读取密码。
- 会话过期时明确提示先在原启动器刷新，不再误报为“没有检测到”。
- 修复 Minecraft 皮肤地址被 macOS 拦截的问题，正版头像现在使用 HTTPS 加载。
- 头像按 PCL 风格显示正面像素头，并正确叠加帽子、头发、眼镜等皮肤第二层。

### 外观与主页

- 深色模式可选择跟随系统、固定浅色或固定深色。
- 主页新增独立“快捷游戏”栏，可与默认主页、本地主页和联网主页同时使用。
- 自动列出最近游戏实例以及各实例最近连接的服务器。
- 点击实例即可切换并启动；点击服务器会选择对应实例并直接进入服务器。

# pcl-macos-updates

Bug Craft Launcher（PCL macOS 独立移植版）的公开更新源与安装包。

## v1.1.3 更新介绍

这一版集中改进下载体验、Mod 版本管理、网络测评和界面细节。

### 下载与加载动画

- 下载资源列表不再显示单独的“查看详情”按钮。
- 点击资源卡片任意位置即可直接进入详情页面。
- 下载页面加载时显示真实进度条。
- 加载动画改为猫咪固定在中间，外圈流动线条围绕猫咪旋转。

### Mod 管理

- Mod 管理列表新增“一键切换”。
- 启动器会查找适配当前 Minecraft 版本和加载器的最新模组版本。
- 切换时保持原有启用或停用状态，并自动安装必需前置模组。
- 详情页选择其他版本后立即开始切换，不再需要第二次点击安装。

### 网络测评

- 百宝箱新增完整的网络测评卡片。
- 可检测 Minecraft、Modrinth 和 GitHub 更新服务延迟。
- 下载少量临时数据测量速度，并显示综合评价、平均延迟和 Mbps。
- 测速数据不会保存到本机。

### 界面修复

- 下载资源、原版游戏和 Mod 管理列表统一为更圆润的连续圆角。
- 点击区域、边框和阴影同步适配圆角。
- 修复启动器自定义最小化按钮。
- 改进 macOS 液态玻璃界面，并保留当前主题配色。

### 版本与校验

- 应用版本为 `v1.1.3`，内部更新码为 `38`。
- 更新包继续只使用 SHA-256 校验。
- Apple Silicon 安装包 SHA-256：`6d009a371ee298ecc1fb3b0e83d2b4cf2336396011f70befcfa77e19efd9ddd0`
- 源码包 SHA-256：`42b716cd2bdab1f660e8080e909f49cc2d46b4706fcce0bcb09af18b713722a7`

当前安装包适用于 Apple Silicon 与 macOS 14 或更高版本。

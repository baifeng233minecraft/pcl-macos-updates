# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.0.3 更新介绍

这一版修复旧版本无法稳定发现更新的问题，让百宝箱不再只是展示入口，新增正版皮肤与头像文件导出，并完善启动器窗口控制。

> 兼容说明：v1.0.3 会强制显示一次更新窗口，确保关闭过“发现更新时显示提示”的旧版本也能看到这次更新；v1.0.3 自身不会重复提示。

### 皮肤与头像文件

- 输入正版玩家名后，可从 Minecraft 官方服务获取并保存原始皮肤 PNG 文件。
- 上传 64×64 或 64×32 皮肤后，可生成并保存 256×256 头像 PNG 文件。
- 头像文件会合成脸部基础层与帽子、头发等第二皮肤层。
- 兼容旧版 64×32 皮肤的透明区域与纯黑帽子层占位规则。
- 获取的皮肤仍可用于启动器头像预览和离线实例皮肤资源包。

### 更新检测

- 修复部分旧版本一直检测不到正式版更新的问题。
- 更新清单同时支持 GitHub Raw、GitHub Contents API 与 jsDelivr 备用源。
- 每次检查附加缓存刷新参数，并同时比较内部更新码和语义版本号。
- 单个更新源不可用时会自动尝试下一个，不再直接判定没有更新。

### 百宝箱

- 内存优化会实际清理启动器网络缓存并归还可回收内存，同时显示处理结果。
- 游戏垃圾清理会扫描全部 Minecraft 文件夹、版本隔离目录、Modrinth 实例和 PCL 缓存。
- 清理前显示文件数量与大小并请求确认，文件移入废纸篓，可以恢复。
- 自定义文件下载新增真实进度、速度、取消、重试、自动避免重名和在 Finder 中显示文件。

### 窗口与标题栏

- 移除透明自定义窗口外围的白色框，让启动器内容直接贴合窗口边缘。
- 在最小化按钮左侧新增重启启动器按钮，主页面与版本设置页面均可使用。
- 重启失败时保留当前启动器并显示原因；成功时自动关闭旧窗口并打开新窗口。

# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.0.5 更新介绍

这一版补齐了世界、Java、手柄和下载任务管理，并集中修复 Modrinth 搜索、版本删除和实例概览等实际使用问题。

### 世界管理与备份

- 版本设置新增“世界管理”，可查看存档大小和修改时间，并打开世界或存档目录。
- 支持将世界备份为 ZIP，备份保存在启动器数据目录中，不受版本删除影响。
- 支持恢复为新的世界副本，不覆盖原存档；删除世界时移入废纸篓。
- 已完成“备份 → 恢复 → 文件逐字节比对”的本地集成测试。

### Java 管理与自动补齐

- 设置新增“Java 管理”，统一扫描系统、Modrinth 和 PCL 已安装的 Java。
- 支持手动安装 Java 8、17、21，并显示架构、版本和来源。
- 游戏启动前会检查所需 Java 主版本，缺少时自动下载匹配版本，不再盲目使用不兼容的 Java。

### 手柄适配

- 启动器可识别当前连接的 macOS 手柄。
- Fabric、Quilt、NeoForge 实例可自动匹配并安装 Controlify 与必需前置模组。
- 不支持自动适配的加载器会明确提示，不会静默修改实例。

### 统一下载中心

- 下载进行时，右下角会以动画显示下载按钮；所有任务完成后自动隐藏。
- 下载页面展示每个任务的进度、速度和状态，并提供总进度条。
- 已接入启动器更新、游戏文件、整合包、Java、Modrinth、Fabric、字体、第三方登录组件和百宝箱下载。
- 百宝箱下载现在会真正保存文件，并支持取消、重试和在访达中显示。
- 已通过本地 1 MB HTTP 文件的完整下载集成测试。

### 游戏崩溃提示

- 游戏异常退出时显示带弹出、缩放和轻微抖动效果的提示。
- 自动汇总退出状态与日志线索，并可生成、查看或打开错误报告。

### Modrinth 与实例修复

- 修复含空格的英文关键词无法搜索，以及可选图片地址缺失导致整批结果解析失败的问题。
- 改进 Modrinth HTTP、网络和返回数据错误提示。
- 支持读取 HMCL `patches[].inheritsFrom` 中的 Minecraft 版本，避免把实例名称误当游戏版本。
- 修复删除版本没有实际执行的问题，删除操作会安全移入废纸篓。
- 修复版本概览图标视图范围错误导致贴图不显示的问题。

### 快捷键

- `⌘1` 启动、`⌘2` 下载、`⌘3` 联机、`⌘,` 设置、`⌘5` 更多。
- `⌘Return` 启动游戏、`⌘O` 版本选择、`⌘J` 下载中心、`⌘R` 刷新、`Esc` 返回。
- 快捷键说明可在“设置 > 其他”中直接查看。

### 游戏安装选项

- 下载游戏时可选择原版或 Fabric，并可选择 Fabric Loader 版本。
- Fabric 实例可同时安装 Fabric API；OptiFine 提供对应版本的官方获取入口。

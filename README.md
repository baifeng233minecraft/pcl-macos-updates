# pcl-macos-updates
PCL macOS 独立移植版的公开更新源与安装包

## macOS v24 更新介绍

这一版为启动器加入多层次、不同节奏的动画，让页面和控件更灵动，同时保持点击即时响应。

### 导航与页面

- 顶部标签加入共享滑动指示器，选中背景会自然跟随页面移动。
- 左侧菜单的高亮背景与竖向指示条会在分类之间连贯滑动。
- 主页面使用方向滑动、轻微缩放与淡入组合，内页和弹窗使用不同的进入方式。
- 设置、下载、实例管理和“更多”页面的分类内容拥有独立转场，不再生硬跳变。

### 控件与内容反馈

- 卡片按不同方向和节奏错峰出现，避免所有内容只使用同一种淡入动画。
- 主要按钮、边框按钮、危险按钮、单选按钮和图标按钮分别使用不同幅度的悬停与回弹效果。
- Modrinth 搜索结果和版本列表支持轻微悬停上浮，保持列表层次清晰。
- 正版、离线和第三方账号面板切换时使用共享选中指示器及内容过渡。

### 启动状态与可访问性

- 登录面板与游戏启动进程面板使用不同方向的进入、退出动画。
- 启动进度条平滑跟随真实进度，阶段文字和最新日志独立过渡。
- Microsoft 登录和启动器更新遮罩使用缩放、位移与淡入组合。
- 所有新增位移、缩放和旋转效果均遵循 macOS“减少动态效果”设置。
- 动画仅响应悬停或状态变化，不增加点击等待时间，也不加入无意义的持续动画。

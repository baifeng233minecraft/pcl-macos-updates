# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.0.8 更新介绍

这一版重写了“帮助”页面，重点解决帮助文案仍像 PCL 原版教程、贴图仍是旧 PCL 贴图的问题。

### 帮助页重写

- 新增 Bug Craft Launcher 专用帮助分类。
- 重写快速开始、下载游戏、社区资源、整合包导入、账号皮肤、实例世界、联机、实验室汉化、个性化更新和故障排查 10 个帮助条目。
- 帮助内容说明本启动器自己的功能与入口，不再沿用旧 PCL 帮助教程。
- 主页回声洞、实验室、联机方式、下载中心、手柄和更新策略等新增功能都补进了说明。

### 贴图替换

- 帮助页截图已换成当前 macOS 启动器真实界面截图。
- 移出旧 PCL 帮助目录，避免旧教程和旧贴图继续进入应用包资源。
- 帮助渲染器现在支持加载应用包内的本地截图，离线状态下也能正常显示图片。

### 版本与更新检测

- 同步应用版本为 `v1.0.8`。
- 内部更新码提升到 `33`，旧版本可以检测到这次更新。

### 验证

- JSON 帮助元数据解析通过。
- 应用内帮助列表实机打开通过，已确认显示新的 Bug Craft Launcher 帮助分类和条目。
- Apple Silicon 应用包构建完成，资源目录检查确认旧 PCL 帮助条目未进入新包。
- 构建包使用本机固定签名身份；当前证书链未受系统完全信任，正式分发仍建议 Developer ID 签名与 Apple 公证。

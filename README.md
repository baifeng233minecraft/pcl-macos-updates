# pcl-macos-updates

PCL macOS 独立移植版的公开更新源与安装包。

## v1.0.6 更新介绍

这一版在顶部加入“实验室”，首个实验功能是面向整合包、模组和资源包的内容汉化工坊，并补齐了完整进度反馈与动画。

### 实验室

- 顶部新增“实验室”入口，实验功能统一以小卡片呈现。
- 新增 `⌘4` 快捷键，可直接进入实验室。
- 加入分段入场、烧瓶摆动与气泡、卡片悬停、扫描流光和结果列表动画。
- 动画会遵循“更多动画”和 macOS“减少动态效果”设置。

### 内容汉化工坊

- 支持整合包、模组、资源包和普通文件夹。
- 支持 `.jar`、`.zip`、`.mrpack`、`.7z`、`.rar`、`.tar`、`.gz` 与 `.tgz`。
- 自动扫描 `en_us` JSON、LANG、Properties 文件，并可读取嵌套压缩包。
- 优先复用原包已有的 `zh_cn` 翻译，常见词汇可离线自动填写，其余内容交给用户确认和编辑。
- 导出为独立汉化资源包 ZIP，不直接修改或覆盖原始文件。

### 代码内英文检查

- 扫描 Java `.class` 常量池中疑似直接写死、会展示给玩家的英文文本。
- 排除内部标识符等明显不应翻译的内容，降低误报。
- 将命中项写入审计报告，避免直接改写字节码造成模组损坏。

### 汉化进度

- 汉化编辑区实时显示“已完成 / 总条目”和完成百分比。
- 新增平滑动画进度条，达到 100% 后自动切换完成状态。
- 编辑、自动填写与加载结果时都会同步刷新，不需要重新进入页面。

### 验证

- 已通过真实 JAR 集成测试：覆盖 `en_us` 扫描、已有 `zh_cn` 复用、常用词自动填写、代码内英文检测、内部 ID 排除、汉化包导出与审计报告。
- Apple Silicon 应用已通过严格代码签名校验，两个发布压缩包均通过完整性测试。
